# Life Time "Time Warp" — shot production workspace

**This repository is the complete and only context for this job.** Everything you need is
here; nothing outside it is relevant. Do not look for a wider project, a git history, or
prior versions of these shots — they exist, they are superseded, and reading them would
actively harm the work.

**Your job:** generate one 12-second shot at a time, exactly as specified, and hand the
clip back to the operator.

## Start here

1. Read `prompts/00-SUPERCOMPUTER-INTRO.md` and confirm it in one sentence.
2. Read `SETH.md` — the character.
3. Open `prompts/SHOT-INDEX.md` and find the shot the operator names.
4. Attach that shot's reference images from `refs/`, in the order its prompt file lists.
5. Paste the fenced prompt block from the shot file. Generate. Nothing else.

Reference images are in `refs/` in this repository — clone it and use the local paths, or
read them from the raw URLs. `refs/` is the authority on how Seth and every location look.

## How a shot runs

1. Open a fresh Super Computer session. Paste `prompts/00-SUPERCOMPUTER-INTRO.md`. Wait for the one-line confirm.
2. Attach the shot's reference images from `refs/`, in the order its prompt file lists.
3. Paste the fenced prompt block. Nothing else — no commentary, no prior context.
4. Download to `outputs/S<shot>-v1.mp4`.
5. Extract frames to `frames/`, run the shot's verification checklist.
6. Pass → mark it in `SHOT-INDEX.md` and move on. Fail → one revision, then keep the better of the two regardless.

## Ordering

Phase 1 (S1, S2A–C) → Phase 2 (S3A–D, S5A–E, S6A–B; S4 is locked) → Phase 3 (S7A–B,
S8A–C, S9). POST does not begin until every shot is a keeper.

## Seth

Six wardrobe plates, all one face: `Seth-Car`, `Seth-Gym`, `Seth-Swim-Glasses`,
`Seth-Swim-Bare`, `Seth-Shower`, `Seth-Towel`. Early forties, receding, patchy stubble,
black rectangular glasses, untrained build. Full sheet in `SETH.md`.

The plates are the authority. Prose only exists to stop drift.

## Non-negotiables

- Two attempts maximum per shot. Never a third.
- A reference-image defect is never fixed in the prompt. Regenerate the image (2–9 credits) and then spend one video (108).
- Shirtless full-body plates trip Higgsfield's NSFW classifier on generation. Edit an approved plate with Nano Banana Pro instead of generating a new one.
- Zero readable text in any frame, ever.
- The man is bemused. A grim performance is a failed generation even if every other check passes.
